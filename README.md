# Raku Twitch Bot

A Twitch-only chatbot and control center for Windows Server.

## Status

Early development (v0.1.0).

## Goals

- Twitch EventSub + Helix API
- Chat commands and timers
- Moderation
- Loyalty / presence tracking
- Giveaways and viewer queue
- Channel point automation
- Stream controls
- Statistics and audit log
- OBS/browser widgets
- Rule-based automation engine

No TikTok or other chat platforms are planned.
